# Car-Sales-Analysis-Dashboard
Interactive Car Sales Analysis Dashboard built using Power BI to analyze sales performance, brands, models, fuel types, transmission, body types, and regional trends. Includes key KPIs and dynamic visualizations to identify sales patterns, top-performing segments, and actionable business insights.
## Project Overview

The Car Sales Analysis Dashboard is an interactive Power BI project designed to analyze car sales data and identify key business insights. The dashboard provides a comprehensive view of sales performance across brands, models, fuel types, transmission types, body types, and regions. It uses KPIs and interactive visualizations to identify sales trends, top-performing categories, and overall business performance.
## Key Insights & Features

* 📊 **Sales Performance:** Analyzed overall sales and revenue performance using key KPIs.
* 🚗 **Brand & Model Analysis:** Identified top-performing car brands and models.
* ⛽ **Fuel Type Analysis:** Compared sales across different fuel types.
* ⚙️ **Transmission Analysis:** Analyzed customer preferences for automatic and manual vehicles.
* 📍 **Regional Analysis:** Examined sales performance across different regions.
* 📈 **Trend Analysis:** Identified sales patterns and changes over time.
* 🎯 **Interactive Dashboard:** Used Power BI filters and slicers for dynamic data exploration.
* 💡 **Business Insights:** Converted sales data into meaningful insights to support data-driven decisions.
